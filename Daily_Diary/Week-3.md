- Learned the concepts of Gini Impurity, Entropy, and Information Gain.

# Day 15 – Regression & Regularization Techniques

**Date:** *20 July 2026*

## Objectives
To understand regression-based prediction and learn how regularization techniques help control model complexity and reduce overfitting.

## Session Overview
The session introduced **Linear Regression** for predicting continuous numerical outcomes. We then explored **Ridge and Lasso Regression** as regularized approaches for improving model generalization.
The session covered the difference between **L1 and L2 regularization**, along with how Ridge retains features while reducing their influence and Lasso can reduce less important feature coefficients to zero.

## Key Takeaways
- Understood the fundamentals of Linear Regression.
- Learned the purpose of regularization in model development.
- Differentiated between Ridge and Lasso Regression.
- Understood L1 and L2 regularization.
- Learned how regularization can help reduce overfitting.

## Learning & Implementation
Implemented Linear, Ridge, and Lasso Regression models using Python and Scikit-learn. Trained the models, generated predictions, evaluated their performance, and compared how different regularization techniques affect model behaviour.

## Project Progress
Explored regression and regularization concepts to understand their applicability to different prediction problems. The session strengthened the understanding of model complexity and provided a basis for selecting suitable algorithms for future project requirements.
