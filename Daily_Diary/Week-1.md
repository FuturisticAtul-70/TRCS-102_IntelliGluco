# Day 3 – Data Cleaning, Preprocessing & Dataset Analysis

**Date:** *2 July 2026*

## Objectives

To understand common data quality problems and learn how to inspect, clean, preprocess, and prepare datasets using Python and Pandas.

## Session Overview

The session focused on **Data Cleaning and Preprocessing**, with emphasis on handling issues commonly found in real-world datasets. We covered **missing values, duplicate records, inconsistent text, incorrect or invalid values, and outliers**.

We also learned basic dataset inspection using `head()`, `info()`, and `describe()`. Different approaches for handling missing values, removing duplicates, cleaning text data, and detecting outliers using **boxplots and the IQR method** were discussed and practiced.

## Key Takeaways

- Understood the importance of data quality and consistency.
- Learned different techniques for handling missing values.
- Practiced duplicate detection and removal.
- Explored text cleaning and data standardization.
- Learned outlier detection using boxplots and the IQR method.
- Understood the importance of saving a cleaned dataset for further analysis.

## Learning & Implementation

The concepts were implemented using **Python, Pandas, and Jupyter Notebook**. I inspected the project dataset, analyzed its quality, practiced missing-value and duplicate handling, performed basic text cleaning, and applied outlier detection techniques.
